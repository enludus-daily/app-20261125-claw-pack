# つかんで荷造り：引っ越しクレーン / Claw & Pack: Moving Day

引っ越しの朝、空っぽになっていく部屋で、物をクレーンでつかんで段ボールに詰める iOS のパズルゲーム（SwiftUI + SpriteKit）。
**クレーンゲームの「つかんで落とす」× 箱詰めパズル**。少ない箱で詰めるほどトラック代が浮く。割れ物は高い所から落とすと割れる。

- だれの：短い時間で「考えて・手で動かす」遊びをしたい人。引っ越し・片付けの「詰める気持ちよさ」が好きな人
- どう使う：部屋をなぞってクレーンを動かす → 「つかむ」 → 箱の上で押して下げる → 離して放す → いっぱいになったら「箱を閉じる」
- 作らなかったもの：荷ほどき（部屋を飾る遊び）、3D、オンラインのランキング、時間制限（急かさない）

daily-ideas の今日の Issue：enludus-daily/daily-ideas#53（監督の指示 #51 の昼の企画）

## うれしい・怖いを数字で（テストで確かめる。`Tests/ClawPackTests.swift`）

| | 決まり | 確かめること |
|---|---|---|
| うれしい | ぴったり詰めると箱が減る（目安＝名人の箱数＋1） | 無料の 24 部屋で、何も考えずに落とすと平均 5 箱前後（4.3〜6.3）、大きい物から隅へで 3〜4 箱（2.8〜4.2）、差が 1 箱以上（計算では 5.3 と 3.1） |
| 惜しい | つかむ強さのゆらぎ：つかみやすさ × (1 − 0.45 × ずれ²) | でたらめなずれで 1 回でつかめる割合が 6〜8 割（計算では約 73%） |
| 怖い | 割れ物は場面の高さの 3 割（約 1.2m）より上から落とすと割れる。重い物（重さ 3 以上）が 1 割より上から落ちてくると下の割れ物が割れる | でたらめに押した長さ（0〜2 秒）で割れる割合が 2〜4 割、下まで下ろせば 0 |
| ふた | 縁から 4 点より上にはみ出すと閉じられない | `canClose` |

## 手応えの表

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | ボタンが 3pt 沈み、影が 4→1pt | selection | （なし：直後のモーター音と重なるため） |
| つかむ（成功） | つめが閉じる 0.12 秒、持ち上げ | impact rigid 0.7 | カチャッ |
| つかみ損ね | 物が少し跳ねて「おしい」の文字が浮く | impact soft 0.4 | 空振りのカシャ＋下がる音 |
| 着地 | 物理で転がる・重なる | impact light 0.5 | 段ボールにトン（重いほど低く大きい） |
| 割れる（失敗） | 物が 1.12 倍に膨らんで消え、かけら 7 つが決まった向きに散る＋「ガシャン」 | error | ガシャン（0.8） |
| はみ出し | はみ出した物が赤く点滅、縁の線が赤く | warning | 2 音の下がる警告 |
| 箱を閉じる（完了） | 前の面がかぶさり、テープが左から伸び、右へ滑ってトラックへ。新しい箱が右から | impact heavy | ビーッ（テープ）→ ポン・ポン（トラック） |
| 部屋が片付いた（場面の切れ目） | 結果のシートで星が 1 つずつ弾む（0.26 秒ずつ） | success、星ごとに medium | 口笛の 4 音、星ごとにキラッ |

動きを減らす設定がオンなら、かけら・テープ・箱の滑り・星の弾みを止めて、値を直接変える。

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）

1. 朝の部屋。ノートパソコンをつかんで、箱の上で低く下ろして放す（割れない）
2. 靴の箱を隣へ。マグを高い所から放して「ガシャン」と割れる
3. 箱を閉じてテープ → トラックへ → 結果の星と浮いたトラック代

## 作り

- `App/Sources/Model`：決まり（`Rules`・`PackSim`）、物 40 種（`Catalog`）、部屋 60（`RoomList`）と毎日の部屋（`Room`）、記録（`Records`）。SpriteKit から切り離してテストする
- `App/Sources/Views/PackScene.swift`：物理（固定の座標 480 × 440 を縦横比を保って縮める）、クレーン、割れる判定、箱を閉じる
- 撮影：`-screenshotScene <名前>`（`_ja` で日本語）。SpriteKit は 1.8 秒後に止まった絵に差し替える。`wide` は size class regular を強制して 2 列を撮る
- 文字：`python3 scripts/gen-strings.py` がコードの `tr("日本語", "English")` から `Localizable.xcstrings` を作る
- アイコン：`scripts/make-icon-claw.py`
